# 테더 KRW-USDT 백테스터

브라우저에서 CSV를 직접 읽어 KRW-USDT 동적 추적형 롱 그리드 전략을 실행하는 단일 HTML 백테스터입니다.

## 실행 방법

`index.html` 파일을 최신 브라우저에서 열고 CSV 파일을 선택합니다. 모든 계산은 브라우저 안에서 수행되며 파일은 서버로 업로드되지 않습니다.

## 주요 개선점

- 중복 HTML 문서를 하나로 정리했습니다.
- CSV 헤더/필수 매핑/기간/수수료/간격 입력 검증을 추가했습니다.
- 실행 전 버튼 비활성화와 오류 표시를 추가해 잘못된 상태에서 백테스트가 실행되지 않도록 했습니다.
- 결과 CSV 파일명을 v2.3으로 갱신했습니다.
